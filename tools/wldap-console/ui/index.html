4 · 接下来做什么

  1. 给探针上电，等状态灯变成「每 2 秒短闪」。
  2. 点「保存并测试」，看到绿色 = 探针在线。
  3. 接好 SWCLK / SWDIO / nRESET / GND，目标板自己供电。
  4. 选目标芯片，点「启动 OpenOCD」，等日志出现 Listening on port 3333。
  5. 在 IAR 里把 GDB Server 地址填 127.0.0.1:3333（不是探针的 IP）。
  6. IAR 连上后，右上角「IDE 已连接」会变绿。

OpenOCD 必须一直开着。关掉本窗口会同时结束它。
